# Push notification copy — Phase 1, both languages

Retention is the reason this app stays installed between actions. Deadline watching is the product.
Titles ≤ 40 chars, bodies ≤ 140. Western numerals in both languages. No marketing sends in Phase 1.

## Deadline watching (the retention engine)
Fires only for programmes the user saved. Three sends per programme, then silence.

## Never send
- Any notification about buying a course or upgrading a plan (App Store §3.1.1 and basic decency).
- More than one deadline notification per day, even across several saved programmes — batch them.
- Anything on the day of a user's saved exam date.
