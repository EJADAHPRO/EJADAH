Before you read on

Assumptions, and the calls I made where the spec was silent

Flagging these first so you can correct me before I build screens on top of them.

Assumed
  • This is the design artifact for Phase 0 — a live, interactive spec sheet. Every value here maps 1:1 to tokens.ts, fonts.ts, strings.ts. I am not compiling an Expo bundle here.
  • Web fonts stand in for the @expo-google-fonts packages — same four families, same weights.
  • Icons below are geometric stand-ins on the 24px lucide grid. Production uses lucide-react-native, stroke 2.
  • Default language is Arabic; this sheet opens in English purely for review convenience.
Decided — please confirm
  • Numeral conflict. §3.8 mandates Western numerals everywhere, but §5.5's Arabic password error reads "٨ أحرف". I follow §3.8: 8 أحرف على الأقل مع حرف ورقم.
  • Arabic heading auto-reduce fires at 12% when the string exceeds 28 characters — below that, Amiri holds the English size cleanly.
  • Letter-spacing on Latin eyebrows is .12em. Arabic eyebrows keep 0 and gain 1px of size instead, so the two read at the same visual weight.
  • Gradient budget of six is counted per viewport, not per screen — a long scroll may pass more than six in total.

§4.2 · the single most important brand rule

Gradient discipline

Six permitted uses. Everything else is solid orange, charcoal or a warm neutral. Six gradient elements maximum in a viewport — this sheet's own hero obeys it.

Permitted
1 · one per screen region
2 · the logo tile
1
2
3 · numbered step tiles
Route to Dubai
4 · one phrase, one heading
CLOSING CTA
5 · one band per screen
6 · active tab indicator
Forbidden — all present in the web build
  • Gradient body text or full gradient headlines
  • Gradient card borders and dividers
  • Gradient icons and icon tiles used as decoration
  • Gradient page backgrounds behind content
  • Gradient on secondary or ghost buttons
  • Two gradient elements adjacent to each other
When an accent is on everything it stops being an accent. Restraint here is what separates the app from a template.

Arabic typography — the six mandatory rules

The failures below are the ones users notice instantly. Each pair shows the defect and the fix at the same size.

1 · Letter-spacing breaks the joins

2 · Playfair has no Arabic glyphs

خارطة مسارك المهني
The top line silently falls back to a system serif. Amiri carries the same editorial register.
3 · Line height must rise

4 · Latin fragments must be isolated

Arabic has no case. The property does nothing and marks the interface as un-designed. Arabic eyebrows gain 1px of size instead of tracking.
