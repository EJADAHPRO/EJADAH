# Bundled font licences

All four families are licensed under the SIL Open Font License 1.1, which
permits bundling in an application.

| Family | Files | Licence | Upstream |
|---|---|---|---|
| Playfair Display | `PlayfairDisplay-Variable.ttf` | OFL 1.1 | github.com/google/fonts — ofl/playfairdisplay |
| Inter | `Inter-Variable.ttf` | OFL 1.1 | github.com/google/fonts — ofl/inter |
| Amiri | `Amiri-Bold.ttf` | OFL 1.1 | github.com/google/fonts — ofl/amiri |
| IBM Plex Sans Arabic | `IBMPlexSansArabic-{Regular,Medium,SemiBold,Bold}.ttf` | OFL 1.1 | github.com/google/fonts — ofl/ibmplexsansarabic |

Playfair Display carries no Arabic glyphs and must never be used to render
Arabic text; Amiri is the Arabic display face for exactly that reason
(`handoff-flutter/02-brand/BRAND_GUIDE.md` §5).
